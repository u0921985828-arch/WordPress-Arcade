Portada de Landrace Hunters con anuncios, aviso de cookies, ads.txt y páginas legales.

== Description ==

* Portada propia: el juego con su botón «Tengo 18 años · Jugar», texto y dos huecos de anuncios.
* Los anuncios se pegan tal cual en Ajustes → Web y anuncios (Mantis, afiliados de bancos de semillas
  o cualquier red que acepte contenido +18 de cannabis). Solo se cargan si el visitante acepta las cookies.
* /ads.txt con las líneas que te dé cada red.
* Botón para crear el aviso legal, la privacidad y las cookies con los datos del titular.
* /privacidad-app/: la privacidad de Dub Siege para Google Play (antes en el plugin Arcade).
* Necesita el plugin Landrace Hunters activo. Va por delante de la Lanzadera.
